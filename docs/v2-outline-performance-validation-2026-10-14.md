# 全文大纲有界性能补救（2026-10-14）

本轮接续 `dot/milkup-v2-plugin-system` 的 `5d82cbe84274677c166efdb324ce8692fc625365`。旧版完整索引已具备正确性，但建树、全折叠和全展开存在数十秒等待。本轮只调整独立大纲插件的索引及折叠算法，SDK 保持 0.1.1，插件为 1.2.0。没有合并视觉分支、合入 v2、发布 npm/Release 或上传 Windows 包。

## 原因与修改

旧版每页八条标题，把标题文本、结构和可见序号放在一起。全局折叠逐条重写可见映射；小页和频繁刷新把 CPU 操作放大成数百次 IndexedDB 往返。首轮 8775 标题完整索引发生 1493 次读事务和 563 次写事务；全折叠发生约 286 次读、275–276 次写。18000 标题全折叠约 594–596 次读、582–583 次写。协议延迟和数据库事务时间相互包含，不能相加为独立耗时。

新索引把 128 条紧凑结构记录、按字节打包的标题和可见性树分开。标题页最多 256 条；叶节点覆盖 128 个标题，内部节点最多 32 个子节点。所有类型共用 24 页缓存，每页至多 64 KiB，单次批量至多 256 KiB/32 个键；预读最多四页。另有当前标题页、根节点、最多六级打开的祖先和最多 500 条呈现记录，不持有全文标题数组或无界页目录。

标题可见当且仅当它的已折叠祖先数为零。子树在源序号中是连续区间，单项折叠只对后代区间加减一，更新边界路径及懒标记；可见序号按树中的计数选取，不再写回全部记录。全展开将默认覆盖数设为零，全折叠设为层级深度，通过内存 epoch 延迟重置；已完成索引的折叠状态重置本身不读写存储，后续呈现仍会读取所需页。单项折叠保留独立覆盖，全局重置后旧覆盖失效。增量追加依据当前祖先状态计算覆盖数，在 128/4096 条扩树边界仍保持一致。

缓存淘汰、每个 4096 行扫描范围结束、完成和显式取消时刷写临时索引，取消刷写失败显示失败。此前逐扫描批次刷写的是临时索引，正文恢复频率完全没有改变。扫描范围、完整性条件、取消/重试、版本失效、只读权限和宿主配额保持原合同。

原生中部滚动回归另暴露出旧活动项跟随标记在新范围返回前重放、把列表拉回尾部的问题。插件现在在接受真实滚动请求时立即清除旧跟随标记，并用请求序号保护异步页读取的提交，旧范围不会覆盖较新的滚动意图。新增延迟存储读取测试验证这两个行为；宿主受控 UI 和 SDK 不变。仅清除跟随标记并不足以消除循环。专门的只读 Worker 轨迹显示：真实滚动请求 5613–5987 后，宿主回传上次收到的 8694–8775，插件却与已经准备好的新范围比较，交替重建两段。现额外记录上次实际返回的范围，用它识别回声。新增测试在修复前真实失败，修复后还验证用户随后主动滚回旧范围仍被接受。同一6秒生产轨迹修复前258条渲染请求/响应、范围来回切换，修复后4条且范围与版本稳定。原生测试等待范围、滚动位置和呈现版本连续稳定，精确源偏移断言保留。

## 局限和环境记录

全文索引仍需数秒至十余秒，18000 标题的全折叠仍有可见等待；不能宣称 Typora 级品质已全部达标。资源数据是整个原生/WebKit 进程的采样 RSS，不是插件独立堆、严格峰值或配额的物理磁盘上界。真实 IME、Windows/macOS、Word 2016 和辅助技术仍需目标环境验收；未重试 IBus。

补采期间执行服务 transport disconnected，终止了测试显示/驱动。已落盘的完整样本保留；未完成部分不计通过。恢复后再次确认未提交代码和旧证据均保留，使用新的测试显示和专用 profile 补缺失样本。18k 额外功能脚本首次选择到面板外的隐藏同名命令，在执行动作前断言失败；修正为面板内选择器后只补跑该功能段，已完成的索引样本保留，失败日志不计通过。另一次小文档点击在索引仍显示部分结果时获取了按钮坐标，完成时工具栏收起使坐标失效；测试现明确等待全文完成，取消测试仍保留部分索引场景。完整回归曾误复用失败后仍安装插件的 profile，在“初始零安装”前置断言停止；改用新 profile，没有卸载或删除旧 profile 来伪造通过。一次恢复启动因未加载用户级 Xvfb 路径失败，日志保留；加载既有环境并确认驱动后才重新运行。资源采样增加逐条落盘，避免断开丢失全部观测。没有删除旧 profile、索引、历史证据或恢复副本。
