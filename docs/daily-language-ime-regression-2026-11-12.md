## #94：有真实界面入口后执行的验收

### 前提及隔离

1. 冻结完整源码 SHA、安装包 SHA、实际 EXE SHA、Windows/Runtime 版本、账号类型和进程出生身份；使用已授权的独立临时账号或临时配置，保留真实用户数据。
2. 在全新临时目录创建 `language-<runId>.md` 与一个另存为目标。`runId` 由 UTC 时间和随机值组成；原文件包含 `BASE_<runId>`。记录原始字节、编码、换行及 SHA-256。
3. 通过实际界面打开文件并输入唯一 `UNSAVED_<runId>`，不要保存。确认编辑器中恰好出现一次、dirty 为真、磁盘仍为原 SHA。不得先保存标记来伪造未保存场景。
4. 用真实控件切换界面语言，记录按钮、选项、提示和是否真的 reload/restart。代码围栏语言和系统输入法切换均不能代替此步骤。缺控件则报告 `blocked: interface-language-control-unavailable`，停止此场景，不强制重载。

### 分支与预期

| 实际产品提供的流程                     | 必须检查的编辑器/文件状态                                                                                                                |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 即时切换且不重载                       | 标记仍恰好一次，dirty 与选区/撤销语义保持，磁盘 SHA 不变；不能仅因没有模态框判失败。                                                     |
| 取消语言更改/取消重启/稍后重启         | 文档仍打开且标记保留，未发生意外退出/重载，磁盘仍为原 SHA。若语言设置已保存但延后重启，分别记录设置与文档状态。                          |
| 明确“保存并重启”                       | 保存完成后才允许退出；磁盘包含完整标记与原文，重启后文件身份正确、标记恰好一次、dirty 状态符合已保存文档。记录新进程出生身份而非仅 PID。 |
| 用户取消另存为、原生保存失败或文件冲突 | 不允许把失败当成功后重载；当前文档、标记、dirty 保留，磁盘按实际错误语义核对，不覆盖另一文件。仅用可控临时目标制造失败。                 |
| 产品提供明确“不保存/丢弃”选项          | 必须实际显式选择后才能允许放弃标记，磁盘原文保持；不能把用户明确丢弃误报为自动丢数据，也不能默认选择它规避保存路径。                     |

另对未命名新文档重复保存目标选择/取消流程；在正常编辑模式和实时预览模式分别执行。保存或取消后继续输入第二个唯一标记，验证文档仍可编辑；通过实际保存、重开和磁盘字节再核对，不能只读某一瞬间的 DOM。重启和强杀不同：强杀只能记录失败清理，不能作为通过。

## #242：真实 Windows 中文 IME 标点矩阵

前提为目标 Windows 中实际可用的 Microsoft Pinyin（或明确记录的其它中文 IME），记录版本、TIP、键盘布局、中文/英文及中英文标点状态。缺少中文引擎或无法显示真实候选窗则记录环境阻塞，不以直接注入 Unicode 补出“通过”。

使用另一个全新临时文件和 `IME_<runId>` 标记，至少覆盖：

1. **真实 composition 与中文标点。** 逐键拼音、观察候选窗、选择候选，接着通过真实键盘输入中文逗号 `，`、句号 `。`、问号 `？`、叹号 `！`、冒号 `：`、分号 `；`。记录实际标点模式和按键映射，不能把英文标点模式产生 ASCII 误判为产品缺陷。
2. **配对符号与编辑交互。** 输入 `“”`、`‘’`、`（）` 等所选 IME 支持的中文配对标点，检查是否丢字、重复、错误配对或跳光标；退格、撤销、重做后精确字符与选区符合操作。若某映射不受 IME 支持，记录原因而非注入替代字符。
3. **输入位置。** 普通段落、列表/任务列表、粗体标记附近与代码块；分别在编辑器源码/实时模式执行，不改动 Mermaid 插件策略来代替编辑器模式。
4. **候选取消与中英切换。** 候选未提交时 Escape 取消不改变已提交文本；中文↔英文切换后分别输入中文与 ASCII 标点，确认不丢失此前内容；composition 提交一次，撤销不残留半个组合。
5. **延迟与落盘。** 每组输入后等待至少 2.5 秒再检查光标和内容，继续输入一个尾标记；保存、正常关闭、重开，核对 UTF-8 字节/Unicode 码点、标点数量和 SHA。有意未保存时验证关闭取消保留标记，最终保存流程保留全文。

证据必须含：候选窗与标点状态截图/录屏、按键顺序、每阶段编辑器文本/dirty/选区、保存前后文件身份与字节摘要、实际关闭结果。WebDriver 可辅助只读核对，但用字符注入绕过 IME 的输入不能记为真实 IME pass。
