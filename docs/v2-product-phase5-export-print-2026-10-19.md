## 实现

独立 `milkup.export-print` 1.0.0 插件仅依赖公开 SDK 0.3.5，提供 HTML、PDF、打印、整篇／选区、图片／纸张／方向选择，以及进度、取消、警告和重试。插件默认不批准敏感输出权限。宿主的 `capture / chooseTarget / write / print / release` 是通用受控能力，不含插件 ID 分支，不向插件公开原文、原路径或任意 HTML 注入入口。

以开始时的选区范围捕获；捕获期间文档身份、版本或保存位置变化即失败，之后移动选区不会改变本次范围。完成后保留该版本的不可变 HTML，后续编辑不混入已有输出。窗口化文档用空 EOF 原生块取得 UTF-16 长度，每次正文及边界读取最多 131072 UTF-16；原生预算错误同样缩窗，LF/CRLF、末尾 CR 和 Unicode 坐标保留。整篇上限 2 Mi UTF-16、200000 行；超长单行不能满足读取预算时显式拒绝。宿主最多保留四份捕获；取消后仍在执行的操作继续计入额度，直至终态。

静态转换采用固定 CSP 和打印样式。普通 Markdown、中文、表格对齐、代码、图片与现有扩展的闭合 MathML／SVG／脚注数据转换为离线 HTML。启用的通用渲染器使用 `target: export`，保持已有输入、输出和超时预算。富渲染片段未支持、超限、失败或选区上下文不完整时保留可读源码并提示；整个捕获超过正文、HTML 或资源总额度则明确拒绝，不截断输出，不把原文降级称为完整排版支持。图片沿用原生受控资源范围：当前已注册文档旁的 `assets/<file>` 或 `*.assets/<file>` 两段路径，支持 PNG／JPEG／WebP，单图最多 16 MiB。任意同目录图片、嵌套路径、绝对路径和远程图片不在该范围内，保留占位与警告；不自动联网下载。包含内嵌图片的完整 HTML 按 UTF-8 总字节数限 32 MiB；PDF 限 64 MiB。

Linux PDF 使用独立、启用沙箱的 WebKit 进程和真正的 GTK 打印后端；脚本、外部导航及网络请求被禁用。保存／打印对话框在受 guardian 管理的辅助进程内，取消可关闭窗口并返回终态。新文件通过 `RENAME_NOREPLACE` 发布；覆盖现有文件先确认，再重验目录身份、目标身份和 SHA。保护当前原文、同 inode 别名及其他注册文档。与现有保存边界一致，不宣称对不合作外部写入者提供操作系统级比较交换。成功提交后晚到取消不删除结果、不误报失败。

PDF 文本诊断进一步发现：新 A4 的 672 个解压流中没有 `/ActualText`，157 个 ToUnicode 表中 19 个含康熙部首映射。对应版本的 [WebKit 字形构建代码](https://raw.githubusercontent.com/WebKit/WebKit/webkitgtk-2.52.6/Source/WebCore/platform/graphics/skia/FontSkia.cpp)只向绘制链提供字形与位置，而 [Skia PDF 代码](https://raw.githubusercontent.com/WebKit/WebKit/webkitgtk-2.52.6/Source/ThirdParty/skia/src/pdf/SkPDFDevice.cpp)需要原文簇信息才能补充 ActualText。这支持后端丢失原文字形对应关系的解释，尚未进行二进制符号级跟踪；不能把换字体或 NFKC 后处理当作完整修复。
