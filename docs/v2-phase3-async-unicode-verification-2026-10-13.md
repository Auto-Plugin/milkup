## 验收矩阵

| 场景                         | 实现／验收                                                                                          | 证据与限制                                           |
| ---------------------------- | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| 切文档后的图片导入           | 销毁使批次失效，停止后续图片导入；桌面 dispatch 再检查当前视图归属                                  | DOM、Chromium 新建文档与历史检查                     |
| 保存／确认框前开始的导入     | 编辑锁使旧导入永久失效，即使锁已释放也不写入；可见取消说明                                          | DOM、浏览器保存快照与 clean 状态                     |
| 导入期间正文变化／仅移动光标 | 正文变化取消并提示重新粘贴；只移动光标仍使用原粘贴选区                                              | DOM；不引入跨事务位置映射                            |
| 导入异常与重试               | 捕获失败、显示错误，不产生未处理 Promise rejection；后续成功清除旧图片错误提示                      | DOM、浏览器 pageerror 和重试断言                     |
| 保存期间外部修改／删除       | 记录通知，在保存结果应用后按最终文档与路径核对；未知／不匹配哈希保留为冲突，阻止自动离开            | 纯函数、浏览器延迟保存／取消确认／重复保存           |
| 自身写入通知与另存为旧路径   | 匹配保存哈希的 modified 通知忽略；旧路径或其他文档通知不污染新副本；未知通知保守保留                | 纯函数；自身通知浏览器路径                           |
| 窗口化内存保存前检查         | 等编辑队列排空后再检查覆盖安全状态                                                                  | 代码检查及既有窗口化／保存回归；原生写入竞态仍未验收 |
| 普通视图 Unicode 键盘        | 左右／Shift 选区、Backspace/Delete 按字形操作；垂直落点向前吸附边界；异常内部代理对落点删除完整字形 | DOM；source/live Chromium 按键与 undo/redo           |
| 换行及历史                   | LF/CRLF 不拆分；删除支持完整撤销／重做；前两阶段保护回归保留                                        | DOM、完整测试集                                      |

字形边界使用平台 `Intl.Segmenter`，只分析当前行，不在每次按键扫描全文。尚未为超长单行作性能验收，也未在当前原生 WebView 验证该 API。

保存通知处理是保守的前端冲突保护：无法证明某个通知对应本次写入时要求用户核对。它不承诺阻止已经发生的外部磁盘覆盖，也不能替代原生端 compare-and-swap／原子替换／文件锁。已经启动的资源写入无法中止；取消后可能留下未被引用的资源文件，本轮不会擅自删除。
