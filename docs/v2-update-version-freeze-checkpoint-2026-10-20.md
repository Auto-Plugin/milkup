## 实现位置与边界

- `apps/desktop/src-tauri/src/update_pe.rs`：只读且有界的 PE/PE32+ 资源解析；限制 section 数、资源大小/深度/分支、语言表和字符串，拒绝重叠区段、循环、歧义与截断。按 [Microsoft PE 格式](https://learn.microsoft.com/en-us/windows/win32/debug/pe-format)、[VS_VERSIONINFO](https://learn.microsoft.com/en-us/windows/win32/menurc/vs-versioninfo)、[String 结构](https://learn.microsoft.com/en-us/windows/win32/menurc/string-str)读取。MSI/ZIP/缺资源等 Windows 格式失败关闭；Linux/macOS 包内版本解析未补齐。
- `apps/desktop/src-tauri/src/update_policy.rs`：私有策略及持久化。记录上限 8 KiB，已有 fs2 文件锁、独占临时文件、同步和既有原子替换函数；损坏文件保留，无隐式重置。应用水位由签名声明推动，不记录错误的本机“未来时间”。同一版本续期及已授权撤回的续期不会误锁重试。
- `apps/desktop/src-tauri/src/updates.rs`：先读取已认证完整声明，再判断是否向用户提供升级；取消/发布共用候选锁，持久化失败清理检查保留位。下载前后及安装前重新授权，安装前重复资源检查。已保存文档、原生确认、签名、下载上限及既有安装失败保护保持原路径。
- `vendor/tauri-plugin-updater/src/updater.rs`：只增加只读 `verified_release()` Rust 接口与私有认证 JSON 副本；改变 public raw_json 后不可把该字段用于宿主安全判断。完整补丁与文件 SHA 已重新从缓存原始 2.10.1 crate 对照生成；Cargo 清单、锁文件、依赖闭包和许可证均未改变。
- `plugins/updates`：独立 Worker 候选升级至 **1.0.1**。终止的下载/安装错误同时保留“重试检查”和“重新下载并校验”；取消失败仍必须先重试取消，不按错误消息文本解析业务。宿主 SDK/权限/注册未增加特定插件逻辑。

独立插件在仓库外只带自身源码和既有公开 SDK 0.2.0 构建/测试，复用已安装工具，没有安装依赖。候选包包含在证据归档中。**本轮没有重建安装器或覆盖既有预装归档**；分发时必须用更新后的独立插件候选构建预装资源，不能把旧预装 1.0.0 的 UI 当作已修复。

## 修复前失败与修复后证据

1. 原 cf7 宿主对“合法签名清单声明 beta.2、合法签名 PE 资源 ProductVersion 为 beta.1”的样本仍返回可发布字节。`red-pe.log` 记录真正的断言失败；修复后同一回归通过。样本没有代码段/入口点，不是可安装软件，从未执行。第一次 harness 使用了不完整的自定义 target，TargetNotFound 日志单独保留，不计作产品失败。
2. 独立插件先运行两个新增回归：终止错误后第二次 check 没有发出、UI 缺少 check 按钮，结果 **2 失败、17 通过**。修复后 **19 通过**。首次执行目录错误的日志单独保留，不计作产品失败。
3. 有效 PE32/PE32+、旧资源误标、每个截断长度、固定偏移损坏、资源循环、重复项、重叠 section、非 PE 格式及逐字节确定性变异均有断言/无 panic 检查。不是全量模糊测试或真实 NSIS 兼容性矩阵。
4. 签名有效期、旧序号、同序号冲突、签名候选撤回、相同版本续期、错误时钟恢复、重启重新读取、文件损坏/超限、锁争用及 Unix 叶子别名已测试。真实 minisign 验证与固定测试时钟共同使用；生产不暴露时钟覆盖或水位重置 IPC。
5. 取消检查后迟到成功不运行持久化回调；旧下载不能清除新下载 abort/发布结果；下载到验签结束时过期会拒绝，过期重试在包 I/O 前失败。修正本机错误时间后原有效候选仍可重试。原网络、重定向、大小上限、签名及保存保护回归仍保留。

## 仍开放

R05 仍需独立核对真正安装载荷和安装后版本；R07 仍需安装器/宿主健康事务与实际应用回滚。端点/密钥、Windows 安装升级矩阵、GUI/IME、DOM/PDF、P7 性能均保持此前开放状态。本分支没有针对这些项目新增实验或修改大纲候选。

本机账户所有者可以删除/改写信任目录，当前门禁不抵御这一权限级别的攻击；首次无历史状态及有效期内的冻结也无法凭本地水位识别。真实信任文件损坏会阻止更新而保留文件，人工恢复/重新信任工作流尚未实现；编辑器和文档存储不因此重置。
