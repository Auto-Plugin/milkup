# 独立插件系统与大纲验收合同（2026-10-14）

> 此文保留 b86edd3 初版区域大纲的设计和验收记录；当前 SDK 0.1.1 与全文分页大纲 1.1.0 的实现、性能和限制见[后续验收报告](v2-full-outline-validation-2026-10-14.md)。

基线为远端及本地一致的 `566babb93fde847251a9f3f458d77c6603bf8ba4`。本轮工作分支为 `dot/milkup-v2-plugin-system`；视觉问题由另一工作分支处理。本分支不修复编辑器焦点框、任务列表或既有四项显示缺陷，不触发 Windows 产物上传、Release 或主分支合并。

## 已有能力与缺口

已有 `PluginManifest`、本地 JSON 归档、安装/启用/禁用/卸载、兼容性和权限声明、Worker/RPC 隔离、文档扫描与 UI 代理、通用 UI 槽位、虚拟列表，以及管理器/代理/隔离的单元测试。`plugins/outline` 已有单独 manifest 和入口；生产宿主没有按 `milkup.outline` 身份分支。不能将这套已有基础描述成从零实现。

仍未满足独立验收：大纲复制了未公开的 UI/生命周期类型；SDK 包版本与宿主声明不一致，缺少可独立消费的 UI 插件合同；大纲没有节点折叠，README 的全量扫描表述与实际区域扫描不一致；既有大纲测试通过直接写开发注册表和 data URL 注入，不能证明正常安装交付。标题扫描从中间行开始时缺少前置围栏上下文；Worker 初始化等待也需要明确失败/超时与资源回收。

## 独立边界

- 插件只依赖公开 `@milkup/plugin-sdk`。manifest、入口和构建产物可单独复制；SDK 本地 tgz 和插件源可在仓库外安装依赖、类型检查与构建，不发布 npm 包、不新建仓库。
- 用户通过正常插件管理器安装 `.milkup-plugin`，启用、禁用、卸载与重启恢复。验收不得手工写注册表来代替安装。
- 插件不能导入宿主私有模块、接触内部 store 或 DOM。使用公开的只读文档扫描、带版本的文档/UI 更新、受控节点输出和导航命令。通用受控树行属性与样式是公开 UI 合同，不增加大纲专用宿主分支。
- 删除插件目录或不安装插件，宿主仍能独立构建运行；禁用/卸载后撤销 UI/命令/Worker/扫描，正文打开、编辑、保存仍有效。

## 大纲行为

支持当前 Markdown 文档模型的 ATX H1–H6、层级缩进、标题点击导航、文档和版本切换更新、当前标题高亮、节点折叠/展开、空文档、source/live。跳级标题按最近较低级标题确定祖先；折叠中的活动标题由可见祖先表达。围栏内伪标题不应出现在列表。

保留有界读取与呈现：每段 8192 行、最多两段 16384 行标题缓存、最多 500 个呈现行。界面明确已加载范围，用户可以分页继续；不把区域窗口称为完整大文件树。围栏上下文必要的前缀扫描分片让出执行权，不能把有界内存等同于常数时间或 200 ms 性能承诺。版本变化取消旧扫描，迟到结果不能覆盖新文档。上下文窗口外的完整祖先链没有加载时不虚构层级。

## 安全与兼容性

使用现有 Worker、受控 UI、文档只读权限和 broker。大纲不申请文件写入、网络、sidecar 或新增持久授权，不改变安全配置，不加载不可信第三方插件。Worker 与禁用全局 API 是执行隔离和能力收口，不宣称可防御任意恶意 JavaScript；本轮只安装可检视的本仓库插件包。若未来要扩展为不可信插件市场，需要单独的威胁模型与安全设计。

不得让插件工作修改原生保存、恢复快照、历史或大文件工作文件协议。通用插件 UI 的 `role`/`aria-level`/`aria-expanded` 等受控属性与 `.plugin-tree-*` 样式是与视觉分支的唯一预期交界，最终整合时按范围核对。

## 验收证据

1. SDK 与插件在仓库外构建，检查插件包无宿主私有导入；改名插件仍可通过公开机制加载，证明没有硬编码身份依赖。
2. 单元测试覆盖层级/折叠/当前标题、空文档、版本与文档竞态、取消和缓存预算，以及 Worker 启动失败回收和围栏上下文。
3. 实际 Linux 生产应用经插件管理器安装打包产物，记录启用、点击导航、编辑更新、切换文件和模式、折叠、禁用、卸载、重启恢复；原始窗口截图实际查看。
4. 使用确定性大文件覆盖有界分页、跨围栏、远处导航和资源，保留原始数据；适用全仓/原生数据安全回归通过后正常提交推送本插件分支，核验 GitHub author/committer。
5. Windows/macOS、真实 IME、Word 2016 和辅助技术仍为目标环境待验，Linux 结果不外推。
