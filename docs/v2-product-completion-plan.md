## 执行约束

- 正常提交并推送专用分支；不合并 main/v2/quality，不强推，不发正式 Release。
- 保留现有恢复记录、原文、保存/Unicode/历史/性能成果；新增 UI 沿用交互模式，不扩大插件权限。
- 更新端点与发布公钥只能由构建端可信配置提供，不能由下载清单、文档或插件指定。
- 默认无发布配置；本地夹具验证不得成为生产跳过签名的开关。测试安装替身只用于验证交互，报告必须与真正的安装执行区分。
- 每阶段归档失败前证据、修复后断言、用户可见截图及剩余边界；真实平台未验保持未验。
