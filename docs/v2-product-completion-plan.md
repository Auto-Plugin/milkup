## P4 本轮实现范围

1. 复用核心事务、Markdown 语法、表格编辑、文件保存和恢复，新增受控资源导入；修复前失败回归及明确支持边界保存在本轮报告。
2. 独立 `formatting` 提供标题、强调、链接、列表/任务、引用、代码、表格的可发现菜单/命令及适当右键操作。表格操作真实编辑行列和单元格，进入独立撤销/重做历史。
3. 独立 `images` 提供本地图片选择/粘贴、文档旁 `assets` 或文档同名资源目录两种相对路径策略；未命名先完成首次保存再导入，取消保存无资源/引用副作用。另存路径变化时先复制资源再保存文档，保留原件；失败只清理本次新建且未被外部修改的副本，不新增外部上传服务。
4. SDK 增量合同兼容已装 0.3.1 官方插件。新编辑入口绑定文档版本与选区，进入既有撤销历史；只读、超限、未知语法或不支持路径明确拒绝并提示，可预判时禁用；不能截断后修改。
5. 七个插件均完成仓库外仅依赖公开 SDK 的构建与测试；Linux 原生按真实安装/审批流程验证，另验收全插件禁用后的基本编辑/保存/恢复。普通/窗口化、source/live、Unicode/选区、宽窄窗、明暗主题和原生缩放的实际覆盖、截图及剩余边界见阶段报告。

6. 公式、图表与脚注是后续阶段扩展，已实现范围与候选包验收分开记录。原候选包的 Mermaid 仅为有界语法子集；当前独立阶段正在验收官方完整 Mermaid 的替换实现，不能将源码实现或旧子集通过当作 P4 的 Typora 目标完成。节点/连线/标签、嵌套/样式及其它图型的缺口、成熟引擎 DOM/强制终止隔离与安全输出桥接的待验证方案见[图表差距](v2-product-phase4-markdown-extensions-2026-10-15.md#图表阶段差距与成熟引擎后续方案)。通用 Linux DOM 后端和安全 SVG 桥接已实现，最终独立包已冻结验证，生产编辑器验收正在进行；P5 输出及既有图片资源限制仍独立保留。

## 持续架构与安全边界

产品插件拥有业务 UI、文案与流程，独立目录、manifest、构建和档案只依赖公开 SDK。宿主只提供通用事务、选区、受控资源/文件选择、权限与生命周期、持久化、基础编辑/保存/恢复及必要无障碍机制，不按产品插件 ID 特判。预装不代表敏感权限已审批；禁用/卸载后不得自行复活。

所有插件均禁用时，基础打开、编辑、Unicode、撤销/重做、保存失败保护、外部冲突和恢复仍需可用。资源句柄与目标授权不能退化成任意路径、网络或执行权限；不把 Linux/浏览器结果称作 Windows 通过。
