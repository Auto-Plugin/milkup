# milkup 2.0.0-beta.3 Windows 手测试用

这是未签名的 Windows x64 测试安装包，不是正式发行。精确源码、安装器 SHA-256、应用映像和预装插件清单以随包 `manifest.json`、`plugins.json`、`SHA256SUMS.txt` 为准。CI 只构建和检查，没有执行安装器，也没有完成 Windows GUI/中文输入法验收。

## 先确认适合试用

1. 请在已有的独立测试环境试用。安装器使用当前用户安装方式，但沿用原 milkup 应用标识，可能覆盖旧安装、复用已有设置/插件并改变 Markdown 文件关联。它不是便携版；换一个安装路径也不保证用户数据隔离。若只有正在使用的旧环境且不确定影响，先暂停并反馈，不要把它当作无风险并行安装。
2. 小包不包含完整 WebView2 Runtime。优先使用已具备 WebView2 的 Windows 环境；保留原默认安装模式，缺 Runtime 时可能提示联网下载。缺失、下载失败或被策略阻止都应记录为环境阻塞，不说明编辑功能已经通过。
3. 解压下载的 Actions artifact ZIP。在 PowerShell 中对实际 `.exe` 文件执行 `Get-FileHash -Algorithm SHA256 .\实际文件名.exe`，与 `SHA256SUMS.txt` 和 `manifest.json` 核对。不要运行哈希不一致的文件。
4. 未签名包可能触发 SmartScreen、安全软件、管理员权限或组织策略警告。请记录完整提示后停止并反馈。不要关闭防护、解除阻止、修改策略或绕过警告来完成测试。
5. 确认可以试用后，由你手动运行安装器。记录安装位置和版本；本清单不要求自动安装、静默参数、更新旧版或执行回滚。

## 准备全新测试副本

把随包 `samples` 文件夹复制到一个新的测试目录，例如 `Documents\milkup-beta3-test`。保留 ZIP 中原始样本不动，所有编辑只在副本上进行，不打开真实工作文档。开始前记录 Windows 版本、输入法、屏幕分辨率、系统缩放、应用缩放和是否存在旧版/旧插件数据。

## 本次 8 项反馈优先复测

若沿用 beta.2 用户数据，应用会保留已有插件与审批状态，不擅自覆盖用户安装。**工作区恢复需要 Workspace 1.0.1**：在菜单→插件检查版本；仍是 1.0.0 时，使用“安装本地插件”选择本 ZIP 的 `plugins/milkup.workspace-1.0.1.milkup-plugin`，在候选详情核对版本、审阅并启用。它使用 SDK 0.3.8，旧宿主不能声称具备新的恢复能力。其余插件以 `plugins.json` 为准。

## 已知边界，不计为本轮手测通过

- Windows 独立 DOM 插件后端和 PDF/打印仍关闭，diagrams/Mermaid 不可用属于已知限制；不要为了启用它们改安全设置。
- 更新签名渠道未配置。真实更新安装、损坏信任恢复、健康确认、自动回滚仍未验收。
- 本包不包含后续 debug/health 实验；不是 Windows 非管理员映像原语验证器。
- 大型/复杂嵌套文档、图片、Word 互操作、辅助技术、断电恢复等不因本次样本通过而视为完整验收。
