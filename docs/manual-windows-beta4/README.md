# milkup 2.0.0-beta.4 Windows 手测试用

这是未签名的 Windows x64 测试包，不是正式发行。精确源码、版本、安装器 SHA-256 和预装插件以 `manifest.json`、`plugins.json`、`SHA256SUMS.txt` 为准。构建检查没有执行安装器，不代表已完成 Windows GUI 或中文输入法验收。

## 开始前

1. 使用已有的独立测试环境。安装器沿用原应用标识，可能覆盖旧安装、复用设置和插件、改变 Markdown 文件关联；换安装路径不能保证用户数据隔离。
2. 小包不含完整 WebView2 Runtime，优先使用已有 WebView2 的环境。缺失时保留原默认下载模式；下载或策略阻止请记录为环境阻塞。
3. 解压 Actions artifact，在 PowerShell 对实际 EXE 执行 `Get-FileHash -Algorithm SHA256 .\实际文件名.exe`，核对 `SHA256SUMS.txt`。不运行哈希不一致的文件。
4. 如遇 SmartScreen、安全软件、权限或组织策略警告，记录原文后停止反馈，不要关闭防护或绕过警告。
5. 由你手动安装。把随包 `samples` 复制到全新测试目录，只编辑副本，不用真实工作文档。

## 优先验证本次修改

| 项目         | 操作与预期                                                                                                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 一步启用     | 菜单→插件，直接点卡片开关；无需进入详情批准。快速重复点击应只执行一次，失败可见且可重试。详情没有批准、拒绝或启禁按钮。                                                       |
| 卡片操作     | 面板和插件动作位于各自卡片，按钮带统一图标。点击图标本身也有效；弹窗关闭后回到原入口。停用插件的“更多”不应提供重载。                                                          |
| 内置更新     | 菜单→关于，版本旁检查更新。当前正式签名渠道未配置，应明确提示；失败不应误报“已是最新”或亮红点。插件列表不再有 Updates，旧目录和数据保留。不要尝试真实安装更新或重置信任记录。 |
| Windows 图表 | 开启 Diagrams，用实时视图查看样本中的流程图和时序图；切源码确认文字完整。此 Windows 归档明确支持受限语法，不支持的图表显示说明并保留源码，不冒称完整 Mermaid。                |

Windows 图表通过受限 Worker 生成静态图形；独立 DOM 插件与 PDF/打印安全门禁仍关闭。它不需要新增 Runtime 或更改系统安全设置。Linux 的完整 Mermaid 归档保持独立。

已有安装的插件版本以卡片详情和 `plugins.json` 对照；未被替换的用户安装与手动待升级包会保留。若版本不符或启用失败，请记录卡片版本与诊断，不删除配置。需要手动导入时，可选择本 ZIP `plugins` 中对应归档，再从卡片开关开启，不需要独立审批步骤。

## 编辑与数据回归

1. 打开 `basic.md` 副本，输入中文与 emoji，保存、退出、重开核对磁盘文字。
2. 点击任务 checkbox，切源码核对 `[ ]` / `[x]`，再撤销、重做、保存重开。
3. 检查表格对齐、长单元格、粗斜体；在代码中按 End，确认光标可见。选择代码语言后撤销，正文不应改变。
4. 检查工作区恢复上次测试文件夹、大纲导航及多侧栏面板分隔条拖动；失效目录应能重新选择，不能循环弹窗。
5. 浅色/深色、宽窗/约 760×520 窄窗、应用缩放 100/125/150/200% 分别核对控件、选区和焦点。Windows 系统 DPI 单独记录。
6. 可选打开 `larger.md` 副本，修改首尾标记并保存重开；实际渲染模式也记入反馈。

恢复记录是异常退出后的本地草稿保护，不等于原文件已保存。正常状态不再显示内部版本编号，备份失败提示和恢复入口仍保留；恢复生成独立副本。

## 未验收边界

真实更新安装、健康确认、自动回滚、损坏信任恢复未验收；本包不含 debug/health 实验。未签名提示、WebView2 前置、Windows GUI/IME/DPI 需要真实手测。图表不支持全部 Mermaid 语法，复杂布局、辅助技术、断电恢复等不能由本次样本代替验证。

填写 `FEEDBACK.md`，保留最短复现步骤和仅含测试内容的截图。若发现丢字或保存损坏，停止编辑该副本并记录最后一次保存时间。
