## 迁移前已确认的合同冲突

1. 迁移前的 `diagrams` 是纯 Worker 插件。官方 `render` 使用 `document`、SVG `getBBox` 和文字长度测量；不能直接放入无 DOM Worker。模拟 DOM 和近似字体测量不等于官方真实浏览器布局。
2. 迁移前的 `DocumentVectorNode` 仅平面基本图元与主题 tone，没有路径、分组变换、裁剪、标记和完整文本布局，无法保真承载官方 SVG。既有导出 serializer 也未完成颜色映射，本阶段不能顺带宣称 P5 已完成。
3. 当前监督 Worker 的 2 秒终止不能终止被移到主 UI/普通 iframe 的同步 DOM 工作。普通 iframe 不是可独立终止的执行单元。
4. Mermaid `securityLevel: strict` 是输入防护之一，不是网络隔离或输出校验的替代品；官方 renderer 可能生成 `foreignObject`、样式及图像资源。必须检查实际输出和资源请求，不能假设 `htmlLabels:false` 足够。

以上分别对应执行环境和输出形式两个问题；不通过放宽超时、关闭 sandbox 或宿主按 diagrams ID 特判绕开。[既有成熟引擎差距方案](v2-product-phase4-markdown-extensions-2026-10-15.md#图表阶段差距与成熟引擎后续方案)。

机制和输出研究已取得上述结果，产品正在按以下边界实现，尚未通过完整验收：

- 插件拥有固定版本 Mermaid、配置、语法与离线 bundle；宿主只拥有任务生命周期、边界和输出校验。
- 独立可信 helper 使用新 WebContext，不加载编辑器、不注入 Tauri 命令桥，不提供文档/文件/网络接口；只接收有界输入并输出有界结果。Linux 原型采用 WebKitGTK 公开 API 与独立结果管道；固定资源映射、严格 CSP、导航/新窗口/下载/权限拒绝分别验证。仅拦导航不能代表子资源被拦。
- 准备阶段与执行阶段分离，准备有原 10 秒上限；从宿主发送实际解析/布局任务开始，原生监督器按单调时钟执行 2 秒硬截止。不会把解析/布局藏进准备阶段。
- 同步死循环必须能终止，编辑器保持响应；必须核对 WebKit/Network 后代，不能将仅 `Child.kill()` 直接子进程退出当作整个任务已终止。
- 每次任务绑定插件生命周期、文档身份/版本与请求代次；取消、停用、卸载、文档切换、超时和异常均丢弃失效输出并回退完整源码，不改变正文、历史或保存状态。
- 候选输出为封闭静态 SVG AST：有限节点/属性、数值/路径语法、局部引用和受控样式，经宿主重新校验和规范序列化后放入图片上下文；不向编辑器 DOM 注入原始 SVG/HTML/CSS。样式必须完整保留或整图拒绝，不能静默清洗后漏画。
- `foreignObject`、不支持的样式/图元及字体布局必须用真实样例决定完整实现方式。隔离栅格化可作为待比较方案，但须明示缩放、文本选择、无障碍和导出损失，不能当作矢量保真已完成。
- Linux process group、Windows Job Object、macOS WebKit 后代生命周期各有平台边界；只宣称实际验证的平台。Linux 已通过上述固定机制原型及首个产品后端探针，完整产品验收仍未完成；Windows/macOS 后端未实现，不外推 Linux 结果。

机制原型至少包含真实 SVG 量字、同步死循环、外部资源与文件/IPC尝试、错误/超限、取消/清理，然后运行官方引擎的完整图型样例。原型结果及第一次失败必须保留；证明机制可行后才扩展公共 SDK/核心合同并添加修前回归。

接线后的 converter04 使用当前必填墨迹字段重新独立执行 68 次原生调用，均正常退出且清理为空。31 个固定合同预期结果全部符合，包括 CSS origin 和文本长度边界；另 37 项矩阵仍是 **30 个官方原样例加 7 个本地探针**，不是 37 个官方样例。矩阵内 30 项转换 ready、7 项明确拒绝；宿主接受其中 29 项，甘特刻度组的文字透明度成本仍有一项真实拒绝。官方部分分别为 26 项转换 ready、25 项宿主接受，本地部分为 4/4。固定集与矩阵共有 48 个 ready 输出，宿主接受 47 个；这些数字不能相加为独立图型或生产通过数。

当前墨迹合同的七组普通原生图片对照均为零像素差，包括真实绘出的 SVG 阴影；根代理实际查看了描边、箭头及阴影的六张原图。七组滚动用例均能通过原生滚轮到达双轴两端并完成清理，但其中四组在最远端有至多 1 CSS 像素的透明栅格余量，导致滚动距离与原 inline 不同，不能称远端截图全等。直接 `overflow:clip` 的候选另在贴着小数边界的图形上损失 11 个抗锯齿像素；当前 WebKit 不支持 `overflow-clip-margin`，因此两个候选均未进入产品。产品保留完整墨迹，明确保留这项小数滚动余量边界，尚待实际编辑器矩阵验收。

普通呈现的规范化仅接受有独立证据的情况：SVG rect 不适用的 box-shadow、circle 不适用的宽高、严格条件下完全裁剪的甘特竖线，以及 CSSOM 已解析且没有语义引用的普通重复 ID。不存在的本地 filter 引用不能改成 `none`：首次这样处理实际改变 388 个像素；保留为宿主生成的必定不存在的本地片段后，原生 PNG 逐字节一致。有效动画、外部资源和无法完整表达的样式仍整图保留源码。

Timeline 的有效 `brightness(1.2)` 仍是一个普通呈现缺口。当前 WebKit 中改成显式 SVG 亮度滤镜产生 36,204 个像素差异，而删除原 CSS 效果虽在该运行时像素相同，也不足以证明语义等价，因此没有静默删除后标记成功。未开启默认关闭且标为 unstable 的 LayerBasedSVGEngine；helper 单独切换该引擎也不能证明编辑器图片上下文相同。Timeline 暂明确回退完整源码，Linux 结论不外推其它平台。

### 首轮 UI RED 的定位与通用修复

独立使用未改写的实际 block、class、ER AST 和公开桌面服务复现：三图各自合法，合并 JSON 只有 111,147 字节，但规范输出合计 305,820 字节，超过原 256 KiB 共享上限。旧服务因此丢弃整个提供者结果；“上下文尚未加载”的旧提示并不能证明上下文读取失败。这是受控公开服务复现，不是假称已捕获首轮原生请求的精确内容。
