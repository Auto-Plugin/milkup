# beta6 右键菜单与悬浮工具栏检查点

当前为内部候选，应用版本仍为 `2.0.0-beta.5`，不是已交付的 beta6 Windows 安装包。首个产品提交为 `b3962099939149abe930d42b8c57f0a79ba009ce`，生产验收发现的模式竞态补丁为 `b7f9cdecfc02c2f0710fc9d6b71c12419364e644`，作者 LarryZhu-dev `<larryzhu@foxmail.com>`；基线是已交付 beta5 的报告提交 `7189a26a0cb055e96a72bd2655b673e067ba3012`。

## 实现与已证明的行为

- 宿主立即提供复制、剪切、粘贴、全选、撤销、重做与分组 Markdown 插入菜单，不等待插件渲染。动作具有宿主 SVG 图标、菜单语义、禁用态和键盘访问。异步剪贴板操作校验文档、版本、选区和取消状态；写入成功后才能剪切，不把权限失败伪装成功。
- 所有插件合计最多三个菜单动作，禁用项也计入。投影使用受控按钮与宿主 SVG，不插入插件自报 SVG；新开菜单同步退役旧输出，结果和点击再次校验上下文。迟到结果、隐藏项或旧选区不能执行操作。
- 插件关闭通知按视图排序，重新打开等待已有通知结束后再校验上下文。第一次实际显示仍执行 mount，避免遗漏实例登记；一次打开只发一次刷新，不在按下与点击之间替换按钮。
- 文档工具栏使用固定位置浮层，锚定可见选区或光标；越界时避让，离开表格、菜单阻塞、实例卸载时立即隐藏。关闭主菜单先解除 inert，再重新计算位置，避免工具栏必须等下一次输入才恢复。
- 新增 `SourceDocumentView.setSelection()` 供宿主全选使用，保留只读选区和窗口化路径，不把字节长度当 UTF-16 位置，不写入历史。宿主编辑 lease 与普通插件 lease 分离；普通插件写入保护未放宽。

## 环境失败与边界

默认沙箱拒绝 Vite 的 Node 子进程（`spawnSync ... EPERM`），经审查允许使用已有本地工具后，最终前端构建通过。未下载依赖。共享 Git hook 调用本候选未安装的 `lint-staged`，`npx` 无输出等待后终止本次 npm 子进程，确认提交未发生；使用 hook 提供的 `SKIP_SIMPLE_GIT_HOOKS=1` 完成提交，格式检查单独执行并留证。全仓格式检查曾只失败于浮层证据 README，随后已格式化并重算清单，148 份原始来源不变。

完整官方 Mermaid 仍未实现。固定官方引擎服务的[方案与权限差异](v2-beta6-mermaid-render-service-decision-2026-10-23.md)已获得用户对有限测试原型的明确批准。原型在独立 `dot/milkup-v2-mermaid-prototype` 分支准备；该授权不包括加入发布包，当前 UI 候选未包含原型，也未改变 Windows DOM/PDF 门禁。PNG 输出不是现有 core 合同，尚需单独实现和验证；不能把完整语法要求写成限制后宣称完成。

没有新 Windows 构建、安装器执行、上传、正式 Release 或 main 合并。实际 Windows GUI、IME、系统 DPI 与安装更新行为仍未验。

## 原生验收发现的失败与修复

第一轮通过 17 步后，缩放步骤未逐级等待原生设置应用，目标 150% 时停在 125%。验收脚本改为每次真实快捷键后等待明确的 100／125／150／200% 确认，保留原目标断言与失败，不修改产品缩放实现。

第二轮通过 20 步、含全部四档普通文件原生缩放，随后在窗口化文件 Source→Live 后，已经观察为 ready 的表格按钮在点击前消失。JSON 失败快照 `commands=[]`；稍后系统截图中按钮已重新出现，因此不能把截图描述为永久隐藏。该链在插件重启后没有打开过右键菜单，新 context-menu 隐藏通知未执行。

进一步先红后绿证明：宿主工具栏上下文未包含 `viewMode`，模式变化后旧 source 按钮仍短暂可见；Formatting 后续重新 capture 先清快照，空输出清掉 DOM。补丁只改三个产品位置：工具栏上下文加入模式、拒绝旧模式迟到结果、宿主导航通知签名加入模式，确保鼠标切换也刷新。新增两个单测均先失败；相关 105 项单测、桌面类型与格式检查通过。真实浏览器普通鼠标／窗口化快捷键两例均从旧模式 8 个按钮即时变为 0；约 255／265 ms 后才显示新模式按钮，随后实际插行、Unicode 输入与两次撤销通过。没有用延时或保留旧按钮掩盖竞态。补丁后完整桌面包再次通过：65 个 Vitest 文件／891 项，加 4 项 Node bootstrap，共 895 项；其它未变包复用最终全仓结果，合计覆盖 2,892 项。

原生复制／剪切均由独立 GTK 客户端读取 `UTF8_STRING` 原始字节，与 CRLF／Unicode 源文本精确一致。两种文件路径的粘贴均遇 WebKit 环境中的系统剪贴板读取失败（未记录底层异常名，不能据此指认某项系统权限设置）；产品显示明确错误、文档未修改。此项是成功处理平台拒绝，**不是粘贴成功**。Windows 剪贴板行为未验。

## 最终 Linux 生产检查点

模式修复后的二进制来自 `b7f9cdecfc02c2f0710fc9d6b71c12419364e644`，23,398,800 字节，SHA-256 `ce34e8222bec1cf4bcf24d494291e00b670221f24dc5855945692908cdfd3a16`；567 个构建输入仍与提交一致，构建前后无漂移。前端构建、离线 Rust release（1 分 52 秒）通过。
