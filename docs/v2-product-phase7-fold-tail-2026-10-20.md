# P7 稀疏折叠读取与重复原生测量（2026-10-20）

本轮修正了独立大纲按父分支串行读取稀疏可见页的问题，但**没有证明端到端折叠稳定达到原 250 ms 预算，也没有证明整体原生性能提升**。P7 继续部分完成。基线失败、候选失败和交叉对照全部保留，不能用功能流程的 exit 0、合并后的 p95 或成功轮次覆盖失败。

精确起点 `cf7d407dbb9416232d4f2163e8cebf9d49798c57`，隔离分支 `dot/milkup-v2-p7-fold-tail`；源码提交 `8f1645cd72522c10de6714b9918d6f0dc5baee38`。只修改 `plugins/outline`，版本 1.3.3 → 1.3.4；应用 2.0.0-beta.1、公开 SDK 0.3.7、宿主、共享样式和锁文件保持不变。未合并或发布。

## 复现与可解释修改

首先固定三轮基线，再固定三轮候选；每轮使用新 profile、完整 18,000 标题 / 36,001 行 / 1,489,012 字节夹具，SHA256 `997d1c7361e2a53082a935070c6f4f38b9668235744fdde5b16b8257c7d2d757`。原生产脚本 SHA256 `b8ccb4322a8068496ffac252245150f7bb3811a1258f90e6773ac61f29534258` 未改：每轮三次完整索引、每种暖态操作 20 样本，以及中部三操作，共 106 条观察。索引在 Live，交互测量明确切到 Source。完成条件仍为可信输入、精确 DOM 状态及三个不同稳定动画帧；不是物理屏幕呈现时间。

基线第三轮折叠 p95 254 ms，重现预算失败。前三轮合并 p95 为 249 ms，恰好会掩盖第三轮失败，因此按轮判定。历史 M02 的 256 ms 只作历史记录，不混入本轮增益计算。

独立有界诊断记录 3,805 事件、0 丢弃，观察开销累计约 214 ms；折叠涉及 19–21 次临时存储读取。诊断最慢折叠 239 ms，没有复现上述 254 ms 慢点，不能把读取认定为全部长尾的原因。并发请求持续时间之和也不是关键路径。记录仅包含方法名、计数、大小、时间和数字 DOM 范围，不采集正文、标题或存储键值。

`Visibility.selectFrom` 改为按树层汇集需要的页，再进入下一层；不再逐个父节点遍历到底。前沿只含至多 16 个请求序号的数字描述，不持有完整树目录或额外页副本。既有 24 页缓存、每页 64 KiB、最多两批并发读取且每批四页、最多 512 KiB 序列化响应、500 行视图上限，以及顺序写入和失败等待规则均保留。没有新增公共 API。

修复前的确定性完成屏障测试实际失败：稀疏可见页需要 8 轮依赖读取，超过 ≤5 的断言；修复后通过。新增 131,073 标题的第三层树回归核对首尾顺序、折叠/展开/再折叠及无额外写入。20 秒仅为这个结构单测的超时，不是放宽原生预算。既有独立层级 oracle、并发与响应大小边界、拒绝/缺页/坏页及完整重试测试继续通过。

六组独立 Linux 生产功能运行通过：普通 8 标题和密集 18,000 标题各自 Source/Live 的真实树键盘、首尾及跨虚拟范围导航、折叠前后选区/光标/版本不变；选区替换后保存、撤销保存、重做保存、再次撤销保存均核对精确字节。另完成普通 Source 编辑 smoke，以及 26,018,029 字节 / 40,001 行 / 8,775 标题长文索引期间输入、撤销保存、切换文档取消与重开。返回正文编辑步骤只对既有 DOM 输入控件调用 focus，选区及正文/历史修改均使用真实系统按键，没有私有编辑状态注入。普通夹具中的中文和全部其他字节得到保留，但不等同真实 IME 验证。
