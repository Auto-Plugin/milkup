## 最短后续路径

1. **当前环境可完成的部分已完成：** 冻结代码/证据对应关系、隔离未接收候选、列明全部门槛。若后续继续代码工作，本环境可先做 R05 的纯代码版本绑定门禁和回滚设计/单测；这仍不能替代真实安装验证。本轮不实施。
2. **先获得两个具体资源：** 与现有 WebKitGTK 2.52.6 匹配的构建环境；可操作的普通用户 Windows 桌面及 IME/辅助技术。现有 Linux 容器只有运行库，标准 Windows CI 不能代替桌面。Windows 隔离路线还需产品架构决策，不能承诺收到环境便立即修好。
