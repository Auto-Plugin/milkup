## 仍可独立推进，但本轮不扩张 QA 的技术项

1. 默认 WebKitGTK 中文 ToUnicode 与 URI 链接仍失败；数字替换与复杂脚本保护也不能由一个数字样例通过消除。私有引擎研究已验证窄补丁，未进入产品，缺可维护发行版交付与安全更新路径。上游材料待审，不代外发、不改系统运行时。
2. 表格标题 d6a0dc18 的 caption 方案已经默认运行时原生反证：标题第1页、首行第2页。后续 43692316332/43693522845 用原二进制和 guard 重现 693 项坐标完全一致；CSS 断页链仍孤行且回归临界短表，长表续页表头也缺失。该机制实验已停止，caption/CSS 链均不集成、不追加同类 CI。其他超大单元格/嵌套结构/字体或脚本全面矩阵未验，不追加无差别测试。
3. 冷首图长尾：已有 ETW 仅能支持隔离 CI 的部分同步刷盘/NTFS 等待，不能归责特定安全服务或推广用户机器。不重复无判别力的普通启动/ETW，不改变持久化保证。[当前代码路径复核](cold-first-diagram-path-review-2026-11-15.md)未找到证据足够的可安全移出工作；已有提前准备、目录刷新修复和占位不重复验收。本轮不作猜测性补丁，以矩阵收口，不新增边缘任务；后续需要可定位具体非必要阻塞或受支持运行时修复的新证据。
4. Linux 应用内检查/下载/验签已经 43698859751 原生验证；系统包替换、安装重启、正式渠道、未来数据迁移、新版本健康握手及自动回滚仍未证明。不得把 QA 禁止安装的编译特性带入产品，或把验签就绪当安装通过。自动回滚尚未实现，是否作为正式要求需明确，不用人工恢复替代。
5. 窗口化 IME、多平台分页与可访问性实测范围仍分别标记；现有局部测试不冒充组合候选全矩阵。历史 dirty-reload 的保护存在但提示可见性未在冲突修复中关闭。

## 确需外部条件/所有者决定的前置

- Windows OS DPI/多屏：43681940229 只证实一个实际 96 DPI/100% 显示器；需授权的隔离交互桌面，跨屏必须有两块不同 DPI 显示器。不用浏览器缩放、虚拟驱动或改安全设置替代。
- Windows 中文 IME：隔离普通用户 TSF 初始化 E_FAIL，尚未进入产品输入；需可用的交互输入法会话。Word 2016、真实纸张/打印机保真需要相应环境/设备。
- 缺 Runtime/断网：现有 runner 已装 WebView2 且没有可靠干净客体；需可用的隔离 VM。不删除系统 Runtime，不动用户机器。
- 正式代码签名、HTTPS 下载/更新端点、公钥/清单续期与发布窗口需所有者批准和配置。当前 endpoints 空、publicKey null；不替用户配置正式密钥，不发布。
