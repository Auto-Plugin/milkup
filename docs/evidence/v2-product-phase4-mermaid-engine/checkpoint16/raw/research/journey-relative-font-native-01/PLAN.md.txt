# Journey relative-font native diagnostic — prepared, not executed

This is a separate research helper, not a production plugin change or official Instance/lifecycle gate. It reuses the one completed fixed-seed renderer capture from `journey-current-native-paired-01`; there is no Mermaid import, parse, layout, conversion or second render in this run. The captured original SVG, canonical SVG and paint evidence are byte-for-byte copied. Old files are not modified.

## Question and limits

Original title `My working day` has `font-size="4ex"`; canonical title declares `33.8125px` from capture-time computed style. Existing 200% comparison differed by1106 pixels in the title region; this does not yet prove a converter defect. This diagnostic distinguishes capture-time fidelity from re-evaluation of original relative font units at a different native zoom. It separately records inline SVG linebox geometry responsible for a possible4px overflow; title and linebox causes must not be conflated.

The canonical image's internal computed styles are inaccessible through `img`; we explicitly record that fact and retain its declared style in canonical XML. No third inline-canonical arm is added. The original is never modified to freeze its font or change display. No clipping, cropping, padding, font override, empty-space removal or accepted pixel threshold is introduced.

## Interpretation

Ifzoom1 already differs, investigate capture/serialization/image rendering rather than attributing to zoom. Ifzoom1 matches butzoom2 differs, inspect original title computedfontsize, font availability, bbox/CTM and canonical declaration before attributing relative-unit resolution. Rootfont alone is insufficient. A changed original `4ex` resolution can represent re-layout in a new zoom rather than failure to preserve the captured diagram. A claim of a product fix still needs a separately reviewed requirement and regression; this diagnostic changes no product behavior.

The4px linebox observation is separately assessed using original inline root dimensions and ancestor metrics versus canonical absolute block image. A future labeled layout control may isolate baseline behavior; it must never replace the untouched original comparison or claim original bytes were changed innocuously.
