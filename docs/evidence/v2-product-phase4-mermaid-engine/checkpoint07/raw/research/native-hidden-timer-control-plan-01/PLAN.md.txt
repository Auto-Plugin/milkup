## Source support and limits

Local pkgconfig identifies WebKitGTK2.52.6. In that exact tag, HiddenPageDOMTimerThrottlingEnabled defaults true and AutoIncreases false for the relevant WebKit configuration; DOMTimer declares a1second hidden-page alignment interval. Alignment is not an unconditional1second delay per callback. [Preferences](https://github.com/WebKit/WebKit/blob/webkitgtk-2.52.6/Source/WTF/Scripts/Preferences/UnifiedWebPreferences.yaml#L3572), [DOMTimer](https://github.com/WebKit/WebKit/blob/webkitgtk-2.52.6/Source/WebCore/page/DOMTimer.h#L60).

view_fixes traced the exact official class route into elkjs0.9.3's fake Worker, with timers on postMessage and the PromisedWorker receive route. The synthetic nested pair is not asserted to reproduce all ELK instructions. Its separate review is research/hidden-page-static-review/review.md SHA b039046c2ba30a3c625186be7af71f9beff73cc84af06cdbb397d324bc3ac212.

GTK documents OffscreenWindow for snapshots without showing a normal window and warns against GtkWindow-specific APIs. [GTK OffscreenWindow](https://docs.gtk.org/gtk3/class.OffscreenWindow.html). WebKit excludes it from tracked on-screen top-levels; its visibility predicate treats mapped widgets without such a top-level as visible. This supports C as a candidate, not an actual runtime observation. [Visibility predicate](https://github.com/WebKit/WebKit/blob/webkitgtk-2.52.6/Source/WebKit/UIProcess/API/gtk/WebKitWebViewBase.cpp#L497), [classification](https://github.com/WebKit/WebKit/blob/webkitgtk-2.52.6/Source/WebKit/UIProcess/gtk/GtkUtilities.cpp#L83).

If A hidden plus material timer delays contrast with C visible plus shorter timers and unchanged class, that supports this mechanism in the measured environment. Class speed alone is not sufficient causal evidence. Non-reproduction remains a valid outcome. Nothing here proves all past deadlines shared this cause or licenses changing the public2s budget.
