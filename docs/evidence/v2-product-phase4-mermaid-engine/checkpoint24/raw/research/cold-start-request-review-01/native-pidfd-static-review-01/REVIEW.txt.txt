Publication
Precreated absolute final directory is opened O_DIRECTORY/O_NOFOLLOW/CLOEXEC and checked sameeuid/exact0700. Ancestor trust is an explicit preparation prerequisite. Exclusive mkdirat(slot) permits one helper; existing slot disables diagnostics. Two deterministic armed/result finals are each<=8192B, with exclusive nofollow0600 temp, fstat owner/type/mode, write_all then linkat without replacement and temp unlink. Bounded bytes/count do not mean bounded syscall duration. Same-UID malicious peers, arbitrary ancestor paths, crash durability and storage failure are not solved by0700; no fsync guarantee is asserted.
Any malformed first matching diagnostic message consumes receiver slot, an intentional one-shot fail-closed behavior. Failure publication can be absent without recorded I/O errno; observer must treat absent result as incomplete. Held status can contain kernel Pid:-1 if target already exited; external validator must reject unobservable/exited targets. Inner Pid is never an outer PID promise.
