What this supports next

This run establishes useful outer-layer localization for five observed successes: the JS-local invoke interval is much longer than its adjacent typed/envelope serialization intervals. It does not separate Mermaid parsing, layout, SVG generation, font/layout waits, event-loop delay or CPU work inside that async invocation. Thus there is no evidence-based product fix or reason to increase budgets from this run, and no basis to label the historical production08 timeout as classDiagram or any particular library phase.

If a future question specifically requires splitting the demonstrated invocation interval, bounded plugin/internal phase observation would answer a remaining attribution question, but run06 alone does not establish that another runtime or invasive inner instrumentation is necessary now.
