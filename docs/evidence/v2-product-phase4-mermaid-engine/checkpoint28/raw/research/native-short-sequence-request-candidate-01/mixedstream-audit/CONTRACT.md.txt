# Mixed-stream offline audit — prepared only

`audit-mixedstream.py` is a new read-only analyzer; it does not import, execute or modify the previous accepted-wire/full-UI/completed-targeted auditors. No runtime file has been consumed. Only AST parsing is performed during preparation. First actual invocation awaits completed cleanup, all-file freeze and Root authorization; preserve stdout/stderr/actual exit in a new directory, never rerun to manufacture completeness.

Input CLI: `--manifest <completed-manifest.json> --manifest-sha256 <exact SHA> --run <runtime root> --report <new external output.json>`. It verifies every manifest file before reading `native-capture/{events.jsonl,status.json,complete.json}`, `evidence/frontend-queue-trace.json`, `driver.log` and `evidence/results.json`. Missing status/complete/frontend is explicitly incomplete and does not discard valid event analysis. Malformed JSON or corrupt frozen bytes are integrity failures, not quietly repaired. No live `/proc`, browser, network, process signal or product command is used.

Native schema derives from frozen three-file candidate `23c8d25e478f58cf7d1401a44c6d8fad3a0e4f59c76c5c2b1fafc6898597f088`, final source/tests manifest `88152ee86e0804a69f0ae5e5e6b88b449ccddb5704394790d04adf854916c501`. Frontend schema derives from `source.v03.json`, candidate SHA `aa22dfba7e22f99a41d2687fc9aee20ee07a81feb60a9092d3bb0f2d6595ef0b`. It uses the new nativeInstanceId copied from the existing trusted endpoint; no client→native mapping is guessed.

Checks and output:

- Full wire UTF-8 length/SHA, render envelope and ID/plugin agreement; owner PID/birth, instance/request key and guardian identity; original caps and all explicit loss/timing/I/O counters; sequence set without requiring file-order monotonicity.
- Every accepted key must have exactly one render-settled/deadline/failed/stop terminal. Cancel is never terminal; null-ID stop/failure closes no request. `eventOk:false` on strict settlement remains a real settled error; deadline/stop eventOk refers to cleanup only. Original render pipe must also be observed. Frame-read is a parsed claim and never independently promoted to settlement.
- Frontend queued JSON is parsed into typed JSON values and compared deeply to native payload. Object order is irrelevant; array order matters; booleans are distinct from numbers; equivalent numeric JSON representations compare equal. Matching also requires nativeInstanceId/requestId/plugin and one unique frontend client job. No raw JSON text-order equality requirement.
- Queue cancellation with no dispatch/native acceptance is reported separately. Active cancellation keeps transport pending. The frozen frontend's dispose revokes that client's outstanding queued jobs; it does not fabricate native terminals. All frontend jobs must close; native-bound dispatched jobs must have a unique captured wire, except explicit post-failed cases.
- Same-App accepted→pipe/frame/terminal and frame→strict-settle spans; signed frame-minus-pipe is explicitly allowed to be negative due to emitting-thread scheduling. Missing or ambiguous frames yield null spans rather than inferred phase times. Frontend queue wait and trace overhead remain on the frontend clock. Native capture counters remain intact; neither is CPU or exhaustive overhead.
- Complete-payload semantic fingerprints count identical requests without request envelope IDs. Readable groups preserve plugin/renderer/document/version/range/theme/width/selection, source hash and literal block content declarations. These are actual captured input properties, not screenshot attribution or proof of which internal Mermaid block ran.
- All frozen driver dispatch keys must equal the accepted set; native trace deadlines must equal lifecycle deadlines. A dispatch tail after recorder closure remains an explicit mismatch. Final markers or a short UI PASS cannot erase it. Actual deadline/native-fail counts and product record tail are reported separately from audit completeness.

Exit 0 means these evidence checks completed without gaps/mismatches; it does not mean the UI passed, the original long-run failure reproduced, or a historical timeout was fixed. Exit 1 preserves an analysis report listing gaps and available valid facts. Integrity/parsing exceptions retain the first stderr/exit and require a separate qualified supplement, not changing defaults.

The prior native candidate manifests remain unchanged. This preparation has its own manifest covering only the analyzer and this contract; no additional sampling framework or synthetic mirror tests were added.
