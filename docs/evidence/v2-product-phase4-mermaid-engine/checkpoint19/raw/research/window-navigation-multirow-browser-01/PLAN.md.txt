## Specific branch

Source `renderSelection` calls `DocumentPresentation.selectionChanged`. Its cache-selection mismatch branch calls `restore(); schedule()` (manager620–633). Restore removes the preview, restores saved row displays, and restores a reading anchor, but does not call `layout` (1194–1233). By contrast `invalidate` calls `restore(); layout(); schedule()` (561–570). Thus a natural scroll may use retained collapsed height deltas before a subsequent layout measures newly literal rows. This is a static possibility, not established native causation; newer reads or observer layout may promptly correct it.
