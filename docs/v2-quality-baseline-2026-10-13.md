## 基线来源

2026-10-13，`Auto-Plugin/milkup` 远端 v2 `f713d91d311ff22e7b19a01b3b94938b714ba375`。开始时工作树干净，本地 `work` 指向 main `513eb48`，fetch 验证远端 v2 后从该提交建立本地跟踪分支。main 遗留的未跟踪 Electron 编译产物移到 `/tmp/milkup-main-build-backup`，没有删除用户源码。未发现项目级 AGENTS.md / .agents/skills；遵循 coding-plan、product-architecture、v1-lessons-and-regressions 和 regression-policy。

v2 为 Tauri + 自研 TypeScript 编辑内核，不是 main 的 Vue/Electron。此前 main 的 73 项测试及 Electron 输入结果不计入本基线。Typora 仅作体验质量参考，没有使用其专有代码或品牌资产。工具不暴露本轮模型标识或推理档位，无法独立核验 gpt-6-astra/high；本轮没有执行模型切换或委派子模型。

## 第一阶段实现

- `document-transition.ts` 统一序列化新建、打开、关闭和退出。先 flush source view 待提交编辑，再判断 dirty／conflict；重复请求不替换原意图。
- 明确操作对象和后续动作。默认焦点为取消；背景 inert；Tab/Shift+Tab 限于弹窗；Escape 取消；返回正文恢复焦点。
- 保存中禁用重复保存和放弃，允许取消后续跳转。已开始的磁盘写入继续完成，取消不会被异步返回撤销。
- 保存取消、写入异常、保存后仍 dirty、文档身份变化都不继续破坏性操作；失败显示在弹窗内，普通保存错误无需打开开发诊断即可看见。
- 保存前锁定交互；保存确认携带提交版本，后续事务保持 dirty。保存版本必须为合法整数，不能倒退或超出当前版本。覆盖普通、memory source、native large save/save-as 调用点。
- Tauri 原生关闭监听与 Windows 装饰分离；各 Tauri 平台都注册关闭保护，浏览器 beforeunload 对未保存内容也有提示，取消卸载不会销毁资源。
- 全仓两个旧格式问题仅格式调整；Playwright 可显式选已安装 Chromium，不需要为了 Linux 改掉默认 Edge。

场景覆盖：

- Ctrl+N/O/W：提示、取消保持正文、继续编辑、显式放弃、连续快捷键不改变待执行动作。
- 保存前新建：取消文件保存保留原文；磁盘失败保留原文；重试成功才新建。
- 写入延迟：仅一次保存；取消后续跳转后即使写入成功也保留当前文档；可继续输入。
- 打开取消／失败：原正文与撤销历史仍在。
- 普通保存失败：非开发模式可见错误；重试成功后错误收起。
- 浏览器重载：取消 beforeunload 后编辑器仍可输入。
- 原有 source/live、选区、滚动、表格／任务列表、Worker plugin、搜索、图片粘贴路径继续回归。

局限：浏览器文件 adapter 的取消／错误／延迟是可控测试注入，不是 OS 文件对话框；不声称真实磁盘写入、原生窗口、IME、Rust tests、长文 benchmark 或安装包通过。保存时新的外部 watcher 事件与磁盘替换之间的竞态仍须原生后续阶段验证；只读／冲突救援另存副本不在本次实现范围。
