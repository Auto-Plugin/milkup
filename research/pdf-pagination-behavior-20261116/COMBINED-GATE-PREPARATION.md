# Later combined fidelity gate — preparation only

`integration-inputs.json` records exact static patch hashes and paths. The
pagination **behavior** files (RenderBlockFlow/Table/TableSection and the local
policy header) are disjoint from the scalar/digit source text bridge and Skia
URI/OutlinePainter behavior paths. This is only a file intersection result,
not proof of ABI, layout, semantics, compilation or combined native acceptance.

The retained scalar bridge is 0002 plus private-header registration 0003; the
independent ASCII digit delta must still be generated with its exact FontCascade
preimage (02d21a897d20141acea1efe446ba73b766e844131c36445da249daeabc2d6217).
Its narrow independent-cluster/full-run/LTR protections must remain, including
negative ligature, combining and reordered text tests. The corrected Noto
`WRAP0123456789` baseline/candidate discriminator remains mandatory, as do
intentional radicals and original Chinese in the same font/page.

URI's fragment/paint-phase repair is **not** just 0001's annotation method:
retaining separate inline regions and the validated per-call dedup/paint clip
logic is required. Adjacent links, multiline, clipped overflow, cross-page
same URI and no-link negatives must remain. Independent printed geometry must
be compared in the same runtime as the actual annotations.

Known integration point: the URI layout and paint observers and pagination
observer all modify PrintContext::spoolPage. The existing exact-source generator
hashes deliberately reject blindly replaying one over the other. A future
combined observation needs an explicit reviewed composition at the final native
paint boundary, retaining both record contracts and same-process attribution.
Do not solve this by dropping source hashes or omitting either diagnostic.

No combined runtime has been built here. The current unique native run tests
read-only tail diagnosis with unchanged behavior patch, not a combined fidelity
candidate. Only after tail and full-direction pagination pass should a single
content-bound combined candidate be compiled and measured on the original
installed package/guard/default sandbox. Production delivery still requires a
maintained, securely updateable runtime path and supported installed-candidate
evidence; a private research prefix or separate historical passes do not supply
that. No system library substitution, user-installed workaround, alternate
engine/output, external issue/PR or production configuration is introduced.
