# One bounded stock paper control

This is a diagnostic control, not an application build or release acceptance.
The 43813631229 candidate produced an empty ninth Letter portrait page; stock
Letter portrait/landscape from the same original input had not been measured.

The explicit `stock-paper-control` operation uses the original 58c78973 deb,
embedded guard, original owned output process/FD protocol, 12 mm native GTK
settings and verified 1024×768 actual window. Only the already-defined matching
paper declaration and native paper/orientation change between cases. IDs/title
are exactly those from the instrumented candidate. No runtime patch or cache is
used. Official Ubuntu runtime and Noto/Poppler versions are pinned to the prior
run; actual mapped stock libraries/executable hashes and inode identities are
retained, with held pidfd ancestry, normal exit and default WebProcess sandbox.
Stock has no diagnostic records; its collector does **not** claim kernel binding
of layout events. The private collector and its stricter contract are unchanged.

Order: original A4 portrait (all 693 word boxes/order must match exactly), Letter
portrait, Letter landscape. Missing identity, unsafe cleanup or failed A4
calibration stops the batch. Original content/header contract failures are kept
per case and do not prevent later directions. The final step still fails if any
contract fails. Last/empty page drawing streams and independent raster/text
counts are retained, without trimming/rewriting the PDF.

Budgets: job 25 minutes, official dependencies 8 minutes (individual install
360 s), assets 3, install 2, native outer 550 s / batch 400 s / each render 60 s,
cleanup 2, artifact 3. Native work has only three fixed cases. Cleanup and raw
artifact collection run after failure. No changes to main, production settings,
notifications, sandbox, output semantics or user data. This does not establish a
cause for tail overflow and makes no behavior fix before the controls exist.

Local checks: five collector/input/scope negative-control tests, seven existing
real-kernel capture tests and six existing candidate tests passed. The tail
inspector independently reproduces page 9 as text/image-free and zero non-white
pixels from the retained original failed PDF; this is analysis, not a new native
run. Cross-job restore of object artifact 14202401300 remains untested and is not
used here.
