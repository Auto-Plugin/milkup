# 导出与打印

`milkup.export-print` 1.0.1 是独立 Worker 插件，只使用公开的 `@milkup/plugin-sdk` 0.3.5。

在侧栏“导出与打印”中选择 HTML、PDF 或打印；支持整篇文档和所选内容、包含或省略图片，以及 PDF/打印的 A4、Letter、横向或纵向。点击输出后会显示捕获的文档版本、行数和资源提示。之后的编辑不会加入本次输出。重试会重新捕获最新内容。

插件需要 `document:read` 与敏感权限 `document:output`，安装后须由用户明确批准。缺少宿主输出支持时显示错误，不使用浏览器下载或假打印代替。菜单可通过宿主通用插件面板入口访问，插件本身不导入宿主文件。

## 当前宿主支持与已知限制

当前宿主输出后端仅支持 Linux。PDF 和打印依赖系统已安装的 Chromium，插件与宿主不会下载浏览器；缺少依赖时会明确报错，不静默降级到旧 PDF 后端。HTML 导出不需要 Chromium。Windows 和 macOS 明确不受支持，调用会返回 unsupported；独立插件可安装不代表这些平台已有可用的导出或打印后端。

历史 1.0.0 Linux WebKit PDF 曾出现图表汉字、emoji、代码引号的复制/搜索丢失；像素可读不等于文字保真，Unicode 规范化也不能修复丢失字符。1.0.1 对接的系统 Chromium 输出须重新检查实际文件的分页、文字复制和搜索，不能把旧后端视觉通过当作新后端验收。物理打印机输出尚未验收。

命令在第一个 `await` 前调用 `host.output.capture`，立即消费真实用户操作授权；命令自身不等待文件选择、写入或打印。HTML/PDF 的关闭面板、取消、禁用与销毁保持现有取消和资源释放行为。迟到的捕获或目标会释放，宿主确认写入成功后不会删除已保存文件。

打印调用开始后，取消只发出取消请求：界面显示“正在确认打印结果”，保留本次操作并禁止再次开始或重复取消，直到宿主返回终态。原生打印已进入提交阶段时，取消最多等待 30 秒确认结果；成功提交显示成功，只有宿主明确返回取消才显示已取消。无法确认结果时，必须先检查系统打印队列，确认没有该任务再重试，避免重复打印。关闭面板或禁用同样发送取消请求，未确认终态前不提前释放打印资源。

## 独立构建与验证

```sh
pnpm install
pnpm test
pnpm build
pnpm verify:external /absolute/milkup-plugin-sdk-0.3.5.tgz /outside/checkout/export-print
```

离线验证脚本只复制本插件，使用给定的公开 SDK tarball，执行 `pnpm install --offline`、构建和测试。已有 pnpm 缓存位于非默认目录时设置 `PNPM_STORE_DIR`；包元数据缓存位于非默认目录时设置 `PNPM_CACHE_DIR`。构建会拒绝除插件自身与公开 SDK 以外的输入，并要求生成的 Worker ESM 没有运行时 import。

产物：`dist/plugin.js` 与 `dist/milkup.export-print-1.0.1.milkup-plugin`。控制器测试覆盖即时捕获、重复点击、版本与警告、路径取消、延迟返回、写入失败与重试、关闭/禁用清理、取消与提交竞态以及缺少宿主的错误。真实 HTML/PDF/打印质量须由集成环境验收。
