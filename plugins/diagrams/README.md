# Milkup Diagrams 1.1.1

独立 DOM 插件，使用固定版本 **Mermaid 12.2.0 完整官方引擎**和公开 `@milkup/plugin-sdk` **0.3.4**。注册 `diagrams.mermaid`，权限仅为 `document:read`。官方解析、布局和真实字体测量在独立原生 DOM helper 中运行；编辑器只接收闭合的 `bounded-svg-v1` 数据，由宿主独立校验后生成静态图片。

本次官方引擎迁移仍在验证，尚未完成产品验收。旧版手写 flow/sequence/pie 解析器已移除，其语法限制和历史测试不再代表本版能力。完整引擎离线打包也不等于所有图型或所有 SVG 效果已经通过转换与像素验证。

## 范围与回退

目标覆盖常用流程图的子图、方向、样式和标签，时序图的分组，以及 class、state、ER、gantt、journey、gitGraph、pie、mindmap、timeline、requirement、quadrant、xy、block 等普通官方图型。最终支持矩阵以真实原生转换、独立宿主校验和像素验证结果为准。尚未支持的效果必须整图保留原围栏并说明原因；不静默删图元或改写输入来通过。

只处理宿主提供的完整、上下文可信的 `mermaid` 围栏。围栏附加参数不猜测解释。Markdown 原文始终保留，插件不执行编辑事务、不读写文件。外链、图片资源、活动动画以及无法完整表示的输出会明确回退；普通样式、标记、渐变、阴影和文字不能靠删除效果来伪装支持。

官方引擎使用 strict 安全配置和固定离线字体序列，不调用 `bindFunctions`，不向编辑器透传 HTML、CSS、原始 SVG、任意 URL 或脚本。文档指令不能改写安全级别、宿主主题和受控字体等固定配置。原生 helper 的资源权限和独立执行期限仍由宿主管理。

## 预算与生命周期

每次渲染输入最多 64 Ki UTF-16、256 行；单图交给 Mermaid 的源码最多 50,000 UTF-16，官方 `maxEdges` 为 500。完整结果受 256 KiB UTF-8 JSON、4096 个计费节点和 64 层深度等共享限制。宿主还独立校验引用展开、坐标、滤镜及栅格工作量；插件测量结果不能代替这些安全检查。

原生仲裁的两秒执行期限不因图型或测量而延长。取消、版本变化、禁用、卸载和迟到结果由普通插件生命周期处理。转换和布局超限会保留源码，不返回不完整的“成功图”。多个围栏合计超预算时返回 `complete:false`，未呈现范围继续显示源码。

`screen` 和 `export` 使用相同的类型化图片语义。该合同可以供后续导出使用，但不代表 PDF、HTML 或打印链路已实现、已验收。

## Sankey 成功结果复用

1.1.1 在插件实例内部复用完全相同 JSON 请求的 Sankey 成功结果，减少重复官方布局。只有官方返回的图型全部为 `sankey`，且结果完整、非空、全部 `ready` 时才保留；错误、部分结果、取消和其他图型不缓存。Gantt 的当前日期标记依赖时钟，始终重新渲染。

缓存最多 4 项，按 FIFO 淘汰；完整 JSON 键和值按每个 UTF-16 码元 2 字节计费，合计不超过 2 MiB。每次返回独立解析的副本，不保留进行中的 Promise，不跨插件实例或磁盘持久化；准备阶段清空。

仅在字体已加载且渲染容器之外无样式表时启用。Document、FontFaceSet、字体 ready Promise、URL、实际视口尺寸或 DPR 变化会清空；渲染前后环境不一致时不存入。这是隔离 helper 已知环境下的保守边界，不是任意 CSS、系统字体变化或中途变化后复原的完整检测。复用不改变宿主校验、取消或执行期限，也不代表历史超时根因已确定或消除。

## 离线构建

依赖使用独立 pnpm 11.7.0 锁文件。公开 SDK 从固定的 `vendor/plugin-sdk.tgz` 输入；仓库保留既有 SDK 0.3.4 原件，确保全新检出可取得冻结构建输入。归档来源、四个公开成员及精确 SHA-256 见 [SDK 来源记录](SDK-PROVENANCE.md)。不得用当前宿主 SDK 重新打包替换，其他 vendor 文件仍忽略。完整 Mermaid 及依赖在构建时打包成单个离线 ESM 文件，禁止运行时外部导入。构建目标为 ES2024；esbuild 不提供浏览器运行时 API 的 polyfill，必须通过实际原生引擎验证。

依赖审查清单记录每个实际输入文件、包版本和许可证哈希，并与构建 metafile 对照。`THIRD-PARTY-NOTICES.txt` 保留对应许可证原文。正常构建不能重解依赖或隐式改写清单；开发中的 SDK 打包、首次锁文件生成和最终冻结外部构建证据分别记录。

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm test
pnpm run build
```

单元测试中的 Mermaid/转换器 mock 仅验证公开渲染请求、错误回退和生命周期，不代表真实官方引擎或像素通过。DOM 转换、宿主独立校验、图片边界和原生像素验证另行记录。
