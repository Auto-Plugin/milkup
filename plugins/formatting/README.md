# Milkup Formatting

独立 Worker 插件，仅依赖公开 `@milkup/plugin-sdk` 0.3.2，声明 `document:read` 与 `document:write`。安装后按宿主提示授权并在插件管理中启用；此插件不申请文件、网络或应用管理权限。

工具条、格式弹窗与编辑器右键菜单共用贡献命令。支持 ATX 1–6、粗体、斜体、删除线、链接添加/修改/取消、无序/有序/任务列表、引用、行内代码和围栏代码块。真实表格操作使用公开 `host.editing.table`：插表、增删行列、列对齐、替换/清空及选择单元格/表格、退出表格。

格式逻辑属于插件；宿主提供通用、有界、带版本与选区校验的快照/原子提交。内存与窗口化文档均通过 `host.editing`；不读取宿主 store、文件系统或 DOM，不调用旧 `context.editor.dispatch`，不依赖插件 ID 特判。

## 操作与边界

- 标题/列表/引用操作作用于选区覆盖的完整行。行内操作保留选区方向和 Unicode 内容；匹配完整 CST 标记时可取消格式。空选区会插入成对标记并将光标留在中间。
- 链接表单保留打开时的快照。编辑器选区或版本变化后提交会被拒绝，用户需点击“重新读取选区”；不会悄悄改写新的目标。
- 每次快照最多 64 Ki UTF-16 文本、256 行；一次事务最多 64 个变更。不会截断文本后应用。超限、复杂嵌套块、跨部分语法、未闭合标记和无法证明的上下文会显示明确错误并保留原文。
- 代码块内不执行普通 Markdown 格式；完整选择已配对围栏或其内容才能取消代码块。CST 不完整或未知上下文时不猜测。
- 表头不能删除，现有表格结构规则在删除列时至少保留两列；表格结构操作要求完整有界表格及单元格内选区。清空单元格保留结构。正文行数 1–64，列数 1–16。
- 文本修改由宿主记录为一次撤销步骤。取消、卸载和禁用会终止未完成请求；菜单隐藏本身不会取消已提交的点击动作。
- 普通编辑、选择、复制、保存和撤销属于宿主，在禁用本插件后仍可使用。

## 独立验证

在仓库外目录仅安装发布 SDK tarball 和公开开发工具：

```sh
node scripts/verify-external.mjs /absolute/milkup-plugin-sdk-0.3.2.tgz /absolute/external-formatting
```

脚本复制本插件目录，安装依赖，执行类型检查、构建和测试，生成自包含 `dist/milkup.formatting-1.0.0.milkup-plugin`；构建会拒绝所有非公开 Milkup 依赖及运行时外部 imports。
